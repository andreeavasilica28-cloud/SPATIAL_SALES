# Spatial Analysis of Retail Sales Dashboard

## 📊 Project Description
This project focuses on analyzing the sales performance of a retail chain by integrating and processing raw data in SQL and visualizing it within an interactive dashboard created in Power BI. The main objective was to obtain a comprehensive view of profitability by region, city, and product category.

## 🛠 Technologies Used
*   **Data Processing & Storage**: SQLite (for complex queries, creating views, and structuring relational data).
*   **Data Cleaning & Analysis**:for preprocessing CSV files.
*   **Data Visualization**: Power BI (for building the interactive dashboard).
*   **Version Control**: Git & GitHub.

## 📈 Analysis Structure
The project involved the following stages:
1.  **Data Preparation**: Cleaning and importing raw data into SQLite tables.
2.  **SQL Modeling**: Creating optimized views to calculate:
    *   Total sales by region and city.
    *   Profit margin percentage for each product category.
3.  **Visualization**: Building a Power BI dashboard that includes:
    *   Analysis of sales and profit distribution.
    *   Use of *Decomposition Tree* for root cause analysis (drill-down).
    *   Dynamic filters for year and month.

## 💡 Key Conclusions
*   The **East** region records the highest sales volume.
*   The **Groceries** category consistently presents the highest profit margin, although the volume is lower compared to electronics or fashion.
*   The dashboard enables the management team to quickly identify underperforming cities and analyze the efficiency of payment methods.
